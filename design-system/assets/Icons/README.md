# Icons

A representative set of the Lucide icons (lucide-react 1.70, ISC) the app uses: navigation (layout-dashboard, clipboard-list, bell), data (landmark, clock), filters (search) and rule results (circle-x, circle-check). The app also uses scroll-text, fast-forward, rotate-ccw, log-out, arrow-right, x, triangle-alert, mail, message-circle and play-circle.

These files are single-ink in light `text` (#333333) because an `<img>` cannot use `currentColor`. In code, render the Lucide components so they inherit text color. 2px stroke, round caps and joins, 24px grid.
