# Logos

GoAudit has no drawn logo. The mark is Lucide's `ShieldCheck` (ISC license) in `accent` — 20px in the sidebar, 24px on the login card — followed by "GoAudit" in the `wordmark` style.

`goaudit-mark.svg` is the mark with its single ink fixed to `brand-blue` (#2659a5), since an `<img>` cannot inherit color. On dark surfaces render the inline icon in dark `accent` (#6b9bff) instead.
